## 📱 Application Overview

This project is a mobile profile application built with Flutter adhering strictly to the **`StatelessWidget`** paradigm. It displays personal profile information, student credentials, an introductory biography, and personal hobbies/interests.

### ✨ Key Features & Personalizations
1. **StatelessWidget Architecture:** The entire interface is structured using immutable `StatelessWidget` classes (`StudentProfileApp` and `StudentProfilePage`) without mutable state or `setState()`.
2. **Visual Change 1 - Custom Dual-Ring Avatar:** A layered circular avatar with custom depth (`#303F9F` Indigo 700 and `#3F51B5` Indigo 500) displaying initials (`BJB`).
3. **Visual Change 2 - Elevated Detail Cards:** Rounded Material 3 cards with custom dividers, elevation, and lead iconography for Student Number, Year/Section, and Email.
4. **Visual Change 3 - Themed Category Chips:** A responsive `Wrap` layout housing custom interest chips with category-specific Material icons (Coding, Vibe-Coding, Gaming, Game Dev, Animations, Anime, Music & Singing, and Learning New Stuff).

## 🚀 Getting Started

### Prerequisites
- [Flutter SDK](https://docs.flutter.dev/get-started/install) (3.x or later)
- Google Chrome, an Android Emulator, or a connected physical device

### Running the App
1. Clone the repository:
   ```bash
   git clone https://github.com/brettjoshbinasbas-ux/binasbas_flutter_student_profile_app.git
   cd binasbas_flutter_student_profile_app
   ```
2. Fetch dependencies:
   ```bash
   flutter pub get
   ```
3. Run on Chrome or connected device:
   ```bash
   flutter run -d chrome
   ```
