1. What is a StatelessWidget, and why is it appropriate for this application?
A StatelessWidget is an immutable widget in Flutter whose state and properties cannot change dynamically at runtime once instantiated. It is appropriate for this profile application because all student information—such as my name, student number, and hobbies—is static and predefined, requiring no reactive updates or mutable state management.

2. What does the build() method return?
The build() method returns a Widget hierarchy that describes the structural and visual presentation of the user interface on the screen. It composes child widgets together (such as Scaffold, Column, Text, and Card) so the Flutter rendering pipeline can lay them out and paint them.

3. What is the difference between MaterialApp and Scaffold?
MaterialApp is the top-level application wrapper that establishes global application configurations such as routing, localization, navigation, and theme color schemes. In contrast, Scaffold is an individual screen-level layout widget that implements the visual presentation framework of Material Design, providing slots for app bars, drawers, and body content.

4. How do Column, Padding, and SizedBox help organize your screen?
Column arranges child widgets vertically along a single axis from top to bottom. Padding inserts designated outer spacing around widgets to keep content cleanly inset from screen edges, while SizedBox enforces precise vertical separation between distinct UI sections to avoid visual clutter.

5. Why did you use SingleChildScrollView in the profile page?
SingleChildScrollView wraps the layout to provide vertical scrolling when content exceeds the physical height of the display viewport. This guarantees that all sections—including the About Me and Hobbies areas—remain fully accessible on devices with smaller screens and prevents layout overflow errors.
